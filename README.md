## What ASL Trainer Does

ASL Trainer is an online educational application for studying and practicing American Sign Language. It offers a dedicated browser experience, so learners can work on their skills without installing a separate desktop program.

The tool can be used to build initial ASL familiarity, revisit material that has already been studied, or fit brief practice periods into a regular learning schedule. Since the trainer is delivered through the web, it is available from a supported browser whenever you are ready to practice.
